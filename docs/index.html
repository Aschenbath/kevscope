Try it on the captured data

Clone the repository and run these commands from its root:

python -m pip install .
kevscope compare tests/data/ipc-inversion.kev tests/data/ipc-inherit.kev --process rtdemo --html comparison.html

Open comparison.html in a browser. Each report is a single file and works offline. For your own application, capture with tracelogger -w, then use kevscope report or kevscope convert for Perfetto.

What the evidence establishes

These are controlled examples, not a guarantee for every workload. The detector excludes unresolved CPU migrations, unbounded READY intervals, missing priority evidence, and process-shared locks without object identity. A report with no identified inversion does not prove that every real-time deadline was met.
