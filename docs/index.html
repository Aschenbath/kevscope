Keep a wait budget in CI

A capture can have zero inversions and still contain a wait that exceeds your budget. In v0.3.2, check each dependency's maximum or p99 wait:

kevscope report tests/data/ipc-inherit.kev --process rtdemo --max-wait-ms 2 --json

This fixed capture has a 2.495 ms maximum wait, so the 2 ms check exits 3. Limits are optional, use unrounded durations, and appear in text, JSON and offline HTML. A capture with no completed reportable waits exits 4.

What the evidence establishes

These are controlled examples, not a guarantee for every workload. The detector excludes unresolved CPU migrations, unbounded READY intervals, missing priority evidence, and process-shared locks without object identity. A report with no identified inversion does not prove that every real-time deadline was met. Budget checks apply to completed reportable waits; use --strict to also reject limited evidence.
